# 架构总览

Hub-develop 的项目按能力分层，通用的底层能力沉淀为上游项目，再以产品化形态对外发布。

## 分层

| 层 | 代表项目 | 说明 |
| --- | --- | --- |
| 桌面 | MChub | .NET 10 + Avalonia 跨平台启动器 |
| 服务端 | JVM-MCL-Server | Spring Boot + Docker 一键部署 |
| 框架 | OWD.K-MD3 | 可复用文档框架（MD3） |
| 系统 | OpenOS | 基于 ChromiumOS 的衍生系统 |

## 设计原则

- **真实优先**：不摆假数据，依赖缺失就硬报错
- **可复用**：一次沉淀，多项目复用，避免重复造轮子
- **开放可控**：优先从源码出发，而非依赖封装的黑盒
- **长期主义**：维护与打磨，和「做出来」同样重要

## 仓库组织

代码仓库按组织划分，主组织为 `Hub-develop`，部分项目位于 `Hub-code-develop`。每个项目均为独立仓库，自带 README 与 CI。
