# 贡献指南

Hub-develop 欢迎一切形式的贡献——从报 Bug 到提交代码。我们相信好的工具先被自己用起来，也欢迎你来一起打磨。

## 提 Issue

发现 Bug 或有想法，直接在对应仓库提 Issue。请尽量包含：

- **复现步骤**
- **期望行为** 与 **实际行为**
- **环境信息**（操作系统、版本号、运行时）

## 提 Pull Request

1. Fork 目标仓库
2. 从 `main` 切出一条特性分支
3. 保持提交小而聚焦，一条提交解决一件事
4. 发起 PR 并清晰描述改动动机

## 代码规范

- **功能必须真实可用**，拒绝占位数据与静默失败
- 提交信息清晰描述「为什么」，而不只是「改了什么」
- 优先从源码出发，掌握每一层的来龙去脉

> 不清楚从哪开始？先从带 `good first issue` 标签的任务入手。
