# 快速开始

欢迎来到 Hub-develop 的开发者门户。本页帮助你把任意一个项目在本地跑起来。

## 前置条件

- 安装 [Git](https://git-scm.com/)
- 根据项目技术栈准备对应运行时：
  - .NET 项目：**_.NET 10 SDK_**
  - Flutter 项目：**Flutter 3.x + Dart**
  - Spring Boot 项目：**JDK 17 + Maven**

## 克隆与安装

```bash
# 以 MChub 为例
git clone https://github.com/Hub-code-develop/MChub.git
cd MChub
```

> 具体依赖安装与构建命令，请参照各项目仓库根目录的 `README.md`。

## 下一步

- 阅读 [架构总览](/docs/architecture) 了解整体设计
- 查看 [贡献指南](/docs/contributing) 参与进来
- 回到 [项目列表](/projects) 挑选感兴趣的方向
